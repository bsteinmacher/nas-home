<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client (Mobile App) → NPM | External traffic entering the NAS network via reverse proxy |
| NPM → Registry Service | Internal traffic within the `proxynet` Docker network |
| Registry Service → Config Files | Read-only access to sensitive configuration files on the host |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information Disclosure | Config Files | Mitigate | Use `:ro` (read-only) volume mounts to prevent any write access. |
| T-02-02 | Elevation of Privilege | Registry Container | Mitigate | Run container as non-root `appuser` (ASVS 14.1.1). |
| T-02-03 | Spoofing | NPM Integration | Mitigate | Uvicorn configured with `--proxy-headers` and trusted proxy settings. |
| T-02-04 | Information Disclosure | REGISTRY_TOKEN | Mitigate | Store token in `.env` file (not committed to git) and use `secrets.compare_digest` in code. |
</threat_model>
